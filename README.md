# 📊 Анализ эффективности маркетплейса 

## 🚀 Описание
Этот проект представляет собой анализ данных маркетплейса стартапа из Бразилии. 
Цель — выявить причины стагнации выручки и определить точки роста продукта с помощью анализа ключевых метрик.

## 🧠 Цели проекта
- Провести диагностику текущего состояния продукта и поведение пользователей.
- Поиск точек роста: выявить потенциальные направления для улучшения ключевых метрик.
- Сформулировать конкретные, проверяемые гипотезы для роста 

## 📝 Задачи анализа
- Когортный анализ месячного retention пользователей.
- Оценка текущего Product/Market Fit.
- Разработка фреймворка ключевых метрик.
- Приоритизация гипотез с помощью фреймворка ICE (Impact, Confidence, Ease).
- Определение метрик для оценки гипотез.
- RFM-сегментация (recency, frequency, monetary).
- Формирование выводов и практических рекомендаций для команды.

## ✔️ Результаты
- Выявлен низкий retention после первого месяца (0,35%).
- Определены 5 ключевых метрик для фокуса команды.
- По ICE-фреймворку выбрана топ-1 гипотеза (630 баллов) и разработана система метрик для оценки результатов гипотезы.
- Выделены ключевые направления для немедленной реализации.
